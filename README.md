# URL Shortener

🔗 Live Demo: https://url-shortener-java-57k9.onrender.com

A URL Shortener built using Spring Boot.

## Features
- Shorten long URLs
- Redirect using short code
- Random short code generation
- Built using Spring Boot

## Tech Stack
- Java
- Spring Boot
- JPA (Hibernate)
- H2 Database
- Thymeleaf
- Docker
- Render
